# Regenradar


Ziel ist es ein kostenloses werbefreies alternative für https://www.wetteronline.de/regenradar zu machen. 

Das ganze soll eine Webanwendung ohne weitere navigation werden. und soll sowohl mobile als auch desktop funktionieren 

Anforderungen: 
- pwa: installierbar als icon auf dem smartphone
- kartenansicht
- Wetterdaten Europaweit
- slider um smooth in der zeit vorwärts rückwärts zu springen
- Auf der karte sollten die niederschlagsflächen klar zu erkennen sein, transitions für die zeiten zwischen den vorhergesagten punkten des dienstes sollten berechnet werden. 
- wir brauchen keine Uhrzeit die vor "jetzt" ist. nur jetzt und die zukunft. 
- wenn ein backend benötigt werden sollte: rust + asyncgraphql
